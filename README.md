# Sonakshi Prasad — Personal Portfolio

A responsive, editorial-style personal portfolio built with plain HTML, CSS, and JavaScript.

## Files
- `index.html` — page content and sections
- `styles.css` — visual design and responsive layouts
- `script.js` — accessible mobile navigation
- `README.md` — setup and deployment guide

## Run locally
Open `index.html` in your browser. For a local development server, open this folder in VS Code and use the Live Server extension, or run Python from this folder:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.

## Publish for free with GitHub Pages
1. Sign in to GitHub and create a **public** repository, for example `sonakshi-portfolio`.
2. Upload `index.html`, `styles.css`, `script.js`, and `README.md` to the repository's root.
3. Open the repository's **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch `main` and folder `/ (root)`, then save.
6. Wait for the deployment to finish. Your public site will appear at a URL similar to `https://YOUR-USERNAME.github.io/sonakshi-portfolio/`.
7. Open the live URL in an incognito/private browser window and test the menu, navigation, and email link.

## Alternative: Netlify
1. Sign in to Netlify.
2. Choose **Add new site → Deploy manually** (the label may vary).
3. Drag the portfolio folder, or a ZIP containing its files, into the deployment area.
4. Use the generated public URL and open it in an incognito/private browser window to verify it works.
